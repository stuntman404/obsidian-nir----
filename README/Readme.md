Научно-исследовательская работа: Стратегии сохранения саспенса в субтитрах
Дата начала работы: 23 октября 2026 г

Тема исследования
Выявление и анализ переводческих стратегий, которые позволяют сохранить эффект саспенса (напряжения) при переводе аудиовизуальных текстов (фильмов и сериалов) с помощью субтитров.

Актуальность
Саспенс создается за счет звука, монтажа, пауз и интонаций актеров. При переводе субтитрами эти инструменты теряются, и перед переводчиком стоит сложная задача - передать напряжение зрителю, используя только текст и жесткие технические ограничения (время показа, количество символов).

Назначение структуры папок
Хранилище организовано по стандарту для исследовательской работы, чтобы упорядочить процесс от сбора информации до готового текста:
- 00_Inbox - Входящие. Сюда попадают быстрые мысли, идеи, ссылки и всё, что требует дальнейшей обработки.
*  01_Literature - Литература. Конспекты прочитанных статей, книг и исследований по теме перевода и саспенса.
*   02_Notes  - заметки. Атомарные мысли и выводы, связанные между собой вики-ссылками `[[ ]]` для построения графа знаний.
*  03_Projects - Проекты. План самой научно-исследовательской работы, задачи и этапы.
*  04_Drafts - Черновики. Промежуточные варианты текста, наброски введения и глав.
*  05_Output - Готовый результат. Итоговые выводы и оформленные материалы.
*   _Templates - Шаблоны. Заготовки для заметок и карточек источников.
*   _Attachments - Вложения. Картинки, скриншоты субтитров и другие медиафайлы.
